# 🎓 Campus Connect Hub 2k26

A modern web platform designed to connect students, share resources, and collaborate within a campus ecosystem.

---

## 🚀 Features

* 🧑‍🎓 Student Registration & Login
* 🔐 Secure Authentication System
* 📢 Share Campus Updates & Announcements
* 🤝 Connect with Other Students
* 📁 Resource Sharing
* 🎯 User-Friendly Interface

---

## 🛠️ Tech Stack

* **Frontend:** React.js, HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Version Control:** Git & GitHub

---

## 📂 Project Structure

```
Campus-Connect-Hub-2k26/
│── client/        # React frontend
│── server/        # Backend (Node.js + Express)
│── package.json
│── README.md
```

## ⚙️ Installation & Setup

### 🔹 Clone the repository

```
git clone https://github.com/pruthvihd/Campus-Connect-Hub-2k26.git
cd Campus-Connect-Hub-2k26
```

---

### 🔹 Install dependencies

#### Frontend

```
cd client
npm install
```

#### Backend

```
cd server
npm install
```

---

### 🔹 Run the project

#### Start backend

```
cd server
npm start
```

#### Start frontend

```
cd client
npm start
```
